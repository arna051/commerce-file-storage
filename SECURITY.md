# Security policy

Report vulnerabilities privately through GitHub Security Advisories. Do not open a public issue containing exploit details, credentials, signed URLs, file contents, or customer metadata.

Only the latest released minor version receives security fixes. Applications remain responsible for authenticating callers and mapping verified identities into `AccessPrincipal`. Buckets should remain private; ClamAV TCP must remain on a trusted network; production credentials must never use the Compose development defaults.
