# Changelog

## 0.2.0 - 2026-11-06

- Add temporary file retention with a seven-day default lifetime.
- Add authorized promotion from temporary to permanent retention.
- Add safe scheduled cleanup for expired temporary objects and metadata.

## 0.1.0 - 2026-11-05

- Initial provider-neutral storage orchestration.
- S3-compatible MinIO provider and resumable multipart uploads.
- Optional Mongoose, NestJS, ClamAV, and Sharp integrations.
- File-level public, authenticated, owner, user, group, role, and service authorization.
